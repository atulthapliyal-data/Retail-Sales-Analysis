 Retail Sales Dashboard | Microsoft Excel

 Project Overview
This project analyzes retail sales data using Microsoft Excel to understand sales performance, product trends, and business insights through an interactive dashboard.

 Objectives

- Identify top-performing products and categories.
- Compare sales across different regions.

- Present key performance indicators through a dashboard.
